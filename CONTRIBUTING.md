# Contributing to Dougbot

Thanks for improving Dougbot! 🛠️

Before opening a pull request, read `README.md`, `SECURITY.md`, and `RELEASE_CHECKLIST.md`. Keep changes focused, explain what they fix, and add a test for behavior changes when possible.

Run `python -m unittest discover -s tests -v` locally. Do not include passwords, invite codes, generated `.env` files, personal conversation logs, live bot state, copied media/transcripts, or model weights without documented redistribution rights.

The project license is still to be selected by the owner. Contribution and licensing expectations should be clarified before external contributions are accepted; an open PR is not permission to relicense someone else's work.

Please disclose when sample text is synthetic, generated, user-provided, or adapted from outside sources.
